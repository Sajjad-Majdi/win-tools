Rust Task Manager and Rust File Explorer 0.2.11: a fast Task Manager and a fast file manager for Windows 10/11.

New in 0.2.11
- Rust File Explorer: the drive list is live. A mounted .iso, a USB stick, a DVD, a subst or a mapped network drive
  shows up or goes away at once, without restarting; a pane inside a removed drive moves to This PC.
- Rust File Explorer: Eject in the right-click menu of a drive (This PC and the sidebar) for disc images, USB drives
  and DVDs. If a program still uses the drive, it says so and nothing is forced.
- Rust File Explorer: read-only discs (DVDs, mounted .iso) get a disc icon, no "almost full" bar, and no
  New, Cut, Rename or Delete; they are not offered in Copy to and Move to.
- Rust File Explorer: search also works inside discs and other drives the search index does not cover.
- Rust File Explorer: Enter on an .iso that is already mounted opens its tab instead of a new one.
- Rust File Explorer fixes: the Details pane shows the right size and dates for files on a disc; the Cleanup
  drive menu follows drive changes; a slow search reply no longer closes the app; less memory at idle.

New in 0.2.10
- Both apps: built-in updates. When a new version is out, a card shows what changed with Update and Later;
  Update downloads it, installs it and starts the app again. Settings > About shows the version and has
  "Check for updates".
- Rust File Explorer: the size slider works in Details view too, and a second slider sets the space between
  items; Grid and Details keep their own values, and both sliders snap back to the standard mark.
- Rust File Explorer: with the Command bar toolbar, the View menu holds both sliders.
- Rust File Explorer: Grid items sit closer together, and the gap stays the same at every size.
- Rust File Explorer fix: disc images (.iso) and other files whose default action is not "open" now open the
  way a double-click in Explorer does (an .iso is mounted).

New in 0.2.9
- Rust File Explorer: Quick settings has a size slider for Grid view; tiles grow and shrink continuously
  (arrow keys work too), and pictures are made sharper for large tiles.
- Rust File Explorer fix: "Set as default" now removes the default verb older versions wrote, so Windows 11's
  main right-click menu shows only its own "Open" (which opens Rust File Explorer). "Open in Windows File
  Explorer", with Explorer's icon, sits under "Show more options"; "Open in Rust File Explorer" is gone there.

New in 0.2.8
- Rust File Explorer: a Details pane (Alt+Shift+P) shows a file's properties, and titles, artists, album, year,
  tags, comments and other writable fields can be edited in place.
- Rust File Explorer: each folder and drive remembers its own view (Details or Grid).
- Rust File Explorer: Grid view shows the first pictures of a folder on its folder icon.
- Rust File Explorer: a Quick settings panel holds layout, sorting, Details pane, hidden items and file name
  extensions. Settings > Layout > Toolbar adds an Explorer-style command bar instead.
- Rust File Explorer: as the default file manager it also takes the "explore" verb and Folder class opens, hands
  Control Panel, Recycle Bin and Network back to Explorer, and keeps folders opened inside an Explorer window
  in Explorer. Its entries now sit under "Show more options" only, and its own menu has "Open in Windows File
  Explorer" with Explorer's icon.
- Rust File Explorer: taskbar jump list with pinned and recent folders.
- Rust File Explorer: the Compact list view is removed; Ctrl+Shift+1 is Details and Ctrl+Shift+2 is Grid.
- Rust File Explorer fix: the Recycle Bin is found by its correct ID.

New in 0.2.7
- Rust File Explorer: the rename box and other text boxes behave exactly like Windows text boxes.
- Rust File Explorer: the picture viewer keeps its window colours after leaving full screen.

New in 0.2.6
- Rust File Explorer: its own picture viewer. Opening a picture shows every picture of the folder in the list order:
  arrow keys, mouse wheel and a filmstrip step through them; zoom, pan, rotate, full screen, delete with Undo,
  and "Open in default app". Settings > Files and folders > "Open pictures in" switches back to the Windows app.
- Rust File Explorer: drag and drop with the Windows drag image; a slow second click on a name renames it.
- Rust File Explorer: tabs sit in the title bar like Explorer and scroll with arrows when there are many.
- Rust File Explorer: every menu row has an icon; Cut, Copy, Rename and Delete sit in a labelled top row.
- Rust File Explorer: Copy to / Move to end with "Choose location...", the Sort menu has Type, pinned folders show
  "Unpin from sidebar", and Details/Grid buttons sit at the right of the status bar.
- Rust File Explorer: when it is the default file manager, folders open in it from everywhere, and the menu offers
  "Open in Windows File Explorer".
- Rust File Explorer fixes: search inside Temp or AppData shows its results, PageUp/PageDown move a full page,
  the copy toast says when nothing was copied, a rename shows which characters are not allowed, and the Space
  preview of a folder shows its item count.

New in 0.2.5
- Rust File Explorer: AI Review sends several requests at once, so it finishes several times faster.
- Rust File Explorer: in a narrow window the Clean up button shrinks to its icon, like New.
- Both apps: the custom accent is a colour field now: click or drag to pick any colour, and the window follows at once
  (the hex field stays for an exact colour).
- Both apps: Blue is a true blue (it read as sky blue), also in dark mode.
- Rust File Explorer: the Windows accent swatch shows the Windows mark, as in Rust Task Manager.
- Rust File Explorer: no stale stripe in the window after a quick resize.

New in 0.2.4
- Rust File Explorer: Cleanup (the "Clean up" button on This PC). It finds space to free in about two seconds:
  temporary files, app caches and crash dumps, developer caches, duplicate files, old installers in Downloads and
  large old files, with how much each drive gets back. Everything goes to the Recycle Bin, and Undo brings the
  whole batch back. Optional AI Review marks what is safe to remove. Windows and program folders are never touched.
- Rust File Explorer: the New menu also makes Word, Excel and PowerPoint files and zip folders (when installed).
- Rust File Explorer: Back after opening a search result returns to the same results, without searching again.
- Rust File Explorer: AI features try again, and then another Gemini model, when a model is busy.

Downloads
- RustTaskManager-<version>-setup.exe    install for the current user (no admin), Start menu shortcut, uninstaller
- RustTaskManager-<version>-portable.exe  run without installing
- RustFileExplorer-<version>-setup.exe   install for the current user, Start menu shortcut, uninstaller
- RustFileExplorer-<version>-portable.exe run without installing

These files are not code-signed yet, so Windows SmartScreen may warn on first start ("More info" > "Run anyway").
AI Search is off by default. Nothing is sent anywhere until you turn it on and add your own key.
