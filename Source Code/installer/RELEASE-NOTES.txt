Rust Task Manager and Rust File Explorer 0.2.3: a fast Task Manager and a fast file manager for Windows 10/11.

New in 0.2.3
- Rust Task Manager: Startup apps show their impact (High / Medium / Low) and are sorted by it, with the top 5
  first and "Show more" for the rest. Sections fold. Disabled apps sit right under the enabled ones; a switch
  animates first and the row moves after a short pause. A details pane shows where each item comes from.
- Rust Task Manager: Windows services that start with Windows are listed last, each with an on/off switch
  (asks for admin rights through UAC).
- Rust Task Manager: Settings always stay in one column; the command line panel left Settings.
- Both apps: a second click on a menu or dropdown button closes it.

Downloads
- RustTaskManager-<version>-setup.exe    install for the current user (no admin), Start menu shortcut, uninstaller
- RustTaskManager-<version>-portable.exe  run without installing
- RustFileExplorer-<version>-setup.exe   install for the current user, Start menu shortcut, uninstaller
- RustFileExplorer-<version>-portable.exe run without installing

These files are not code-signed yet, so Windows SmartScreen may warn on first start ("More info" > "Run anyway").
AI Search is off by default. Nothing is sent anywhere until you turn it on and add your own key.
