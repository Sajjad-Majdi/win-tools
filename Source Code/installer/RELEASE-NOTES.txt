Rust Task Manager and Rust File Explorer 0.2.1: a fast Task Manager and a fast file manager for Windows 10/11.

New in 0.2.1
- Rust Task Manager: a new Performance page (CPU, memory, disks, network and every GPU, with "used of total" facts);
  process groups (Apps / Background / Windows) with a calm order; a collapsible sidebar; confirms before ending or
  restarting critical or multi-process apps; real signature checks.
- Rust File Explorer: This PC start page; the Desktop includes the Public Desktop; real icons for files, shortcuts and
  custom folders; "Open with" with app icons and a one-click default per file type; type-ahead select; tooltips;
  Extract never overwrites; folder sizes from Everything; a scrollable, manually collapsible sidebar.
- Both: the accent colour you pick themes the whole window (with a Colour strength setting), and Transparency works.
- The Rust File Explorer setup also installs Everything (voidtools, MIT) when it is missing.

Downloads
- RustTaskManager-<version>-setup.exe    install for the current user (no admin), Start menu shortcut, uninstaller
- RustTaskManager-<version>-portable.exe  run without installing
- RustFileExplorer-<version>-setup.exe   install for the current user, Start menu shortcut, uninstaller
- RustFileExplorer-<version>-portable.exe run without installing

These files are not code-signed yet, so Windows SmartScreen may warn on first start ("More info" > "Run anyway").
AI features and meaning search are off by default and are not included in these files.
